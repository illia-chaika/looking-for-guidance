## Changes from the original (November 2026)

- The general-purpose coding chat became a gameplay adviser for World of Warcraft: Forever: a fixed adviser role,
  an isolated agent profile, and a local MCP server that serves character snapshots, recipes, details and memory.
- A field journal was added: overview cards, eight sections, hidden research jobs with validated answers, a feed of
  Blizzard's hotfixes and known issues.
- Per-character conversations and memory, Shift-click links, colour emoji, appearance and language settings,
  eleven interface languages.
- Transport: 512 one-shot payload channels instead of 128, a bounded polling budget, a minimum spacing between
  frames, check frames that rebuild up to six missed frames in a row, automatic resend of unacknowledged packets,
  diagnostics for missed frames.
- Claude Code as a second adviser for the game: chosen in the companion's menu, confined to the game data server
  and web reading, with journal research through one-shot jobs.
- Either adviser works without the other: the companion picks Claude Code when it is the only one installed,
  creates the Codex profile itself on first use and starts the ChatGPT sign-in from its menu.
- Journal research runs only on request unless the player switches it to automatic, within a daily cap the player
  sets; the adviser's remaining allowance is shown in the game where the provider reports it.
- The chat draws Markdown tables, headings and numbered lists; a table too wide for the window is shown as a list.
- The companion's menu in eleven languages, following the system language.
- Optional auction prices: the player's own Battle.net API client, entered in the companion's menu and kept in the
  system's credential store (the keychain on macOS, Credential Manager on Windows), an hourly snapshot of the
  character's auction house from Blizzard's Game Data API, and a price tool for the adviser; an upgrade search per
  equipment slot that takes slots from the world dataset and lets the game judge the candidates.
- Auction snapshots from the project's mirror at `api.lfguidance.com`, so that prices need no Battle.net client of
  the player's own; the companion uses it unless one is stored or the mirror is turned off.
- A world dataset at `data.lfguidance.com`: quests, NPCs, items, spells and places merged by the project's backend
  from ForeverDB's add-on data, Blizzard's Game Data API and the numbers in the game client's tables, downloaded once
  a day and searched by two adviser tools.
- What changed is matched on the player's computer: Blizzard's hotfix notes resolved to game IDs through the world
  dataset and the data changes the project's backend finds in the game client's tables, compared with the character's
  quests, zone, gear, bags, spells and professions; a notice once per new match, an adviser tool, and the adviser's
  summary only on request.
- New artwork for the journal, generated by `tools/build-journal-art.py`, and a compass icon for the app.
